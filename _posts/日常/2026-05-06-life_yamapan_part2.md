# ヤマザキ春のパン祭り、皿を交換する
今年は皿２枚分のシールを集めたわけで、シールの紙が２枚手元にある。
例年ならカウンターに持っていけばその場で交換できた。
今回は首都圏に引っ越したため簡単には行かないようだ。
# 品切れという現象
常連のスーパー３つのうちの、最も交換しやすそうなスーパーに行った。
皿は品切れだという。入荷もいつになるか分からないという。
# 大手スーパーならカウンターがある
大手スーパーで簡単に皿交換ができるのはカウンターがあるからだ。
カウンターがない店舗は交換が難しいのではないか、と察した。
# カウンターレジ
中・小規模スーパーの場合はカウンターレジが存在する。
節分の恵方巻注文でカウンターレジの存在すでに体験ずみである。
一般人にレジとカウンターの違いは分かりにくい。
通常のレジと見た目は同じだが、ゴチャゴチャと物が置かれた机が後ろにあるレジはカウンターレジでいろいろな受付をやっているのである。
例えば、節分が近づくと注文した恵方巻を取りに行くときなどはカウンターレジに行く。
# 店舗によって在庫量がちがう
カウンターレジがあったとしても、在庫がなければ交換できないし、在庫量が少なければ交換を渋る事態が発生する。
# パンを買った店で交換するのが基本
色々調べていくと衝撃的な事実が発覚した。パンを買った店で交換するルールが存在した。
紙に店舗名が印刷してある場合はこのルールが適用される可能性がある。
また、店によって特別なシールを貼ってあり、自分の店で買ったパンかどうかが分かるようにしてある店舗もある。
たいていの場合は見た目では区別できないのでフリーで通る。一般人にはわからないはず。
# つまり交換しやすい店舗とは
カウンターレジがあり、皿の在庫量が豊富で、フリーで通過する店舗、という条件が揃う必要がある。
そうなると、あのスーパーしかない。一つに絞られた。
事前の調べでは、フリーで通過するという情報を得た。
# 締め切りギリギリでは遅いので早目に
早速皿を貰いに別のスーパーへ向かった。
一応買い物を済ませてからレジに並んだ。
# 店員に聞く
カウンターレジらしき所が見当たらない。
皿交換は可能かどうかを尋ねてみると、カウンターレジに行くように言われた。
つまり、交換が可能。
しかしカウンターレジが分からない。
# パソコン一台の前で立っている人、そこがカウンターレジ
コチャゴチャ物が置かれあるテーブル＝カウンターレジという定義が崩れた。
ゴチャゴチャテーブルは奥の方にあるらしい。従ってパソコン一台置いてその前に立っているというわけだ。
シールの紙２枚を渡し、買い物かごから商品をマイバックに移し終えた後に店員がやってきて皿２枚を受け取った。
今年も達成した。気分がいい。
# 使い道があまりない
今年の皿はやや小さめで、現在使っているトーストを置く皿と同じ大きさだ。
パスタを入れるとあふれ出す。
